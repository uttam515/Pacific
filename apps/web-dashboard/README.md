# OFFGRID Web Dashboard

> **Lead:** Engineer 1  
> **Stack:** React + Vite + TypeScript + TailwindCSS / Lucide-React

This application provides the central command and operations dashboard:
- Real-time visualization of mesh topology and connected nodes.
- Emergency SOS triage and incoming alert feed.
- Global announcements management.
- Synchronization and gateway node telemetry.

To get started:
```bash
pnpm install
pnpm dev
```
